Fun with Filters and Frequencies!

Overview

In this project I explored spatial filtering and frequency-domain thinking to build classical image processing effects from scratch. In Part 1, I implemented convolution, finite difference filters, and smoothed derivatives (DoG) to detect edges more robustly. In Part 2, I created frequency-based effects including sharpening, hybrid images, Gaussian/Laplacian stacks, and multi-resolution blending (the classic oraple!).

Part 1: Fun with Filters

Building intuition with 2D convolution, finite differences, and smoothed derivatives (DoG).

1.1 Convolutions from Scratch

I implemented 2D convolution from scratch using two approaches: a 4-loop version and an optimized 2-loop version. Both implementations handle zero-padding automatically by padding the input image based on kernel dimensions (pad_h = kh//2, pad_w = kw//2). The key insight is properly flipping the kernel during convolution - in the 4-loop version, I flip by indexing K[kh-1-m, kw-1-n], while in the 2-loop version I pre-flip the entire kernel with K[::-1, ::-1]. Both methods were verified to produce identical results to scipy.signal.convolve2d with maximum difference of 0.0.

1.2 Finite Difference Operator

Applied finite difference operators to compute image gradients and detect edges. I used Dx=[1,-1] and Dy=[[1],[-1]] kernels to compute horizontal and vertical derivatives respectively. The gradient magnitude was calculated as mag = sqrt(Gx² + Gy²) and normalized to [0,1]. For edge detection, I thresholded the gradient magnitude at τ=0.174, chosen empirically to balance between detecting true edges and suppressing noise. This simple edge detection approach reveals the image's structural boundaries but is sensitive to noise.

1.3 Derivative of Gaussian (DoG)

Improved edge detection by first smoothing with a Gaussian filter before applying derivatives. I used an 11x11 Gaussian kernel with σ=1.0 to suppress noise while preserving important edges. Two approaches were compared: (1) smooth image then differentiate, and (2) create DoG filters by convolving Gaussian with derivative kernels, then apply once. Both methods are mathematically equivalent due to convolution associativity: (G * I) * D = I * (G * D). The DoG approach is more efficient, requiring only one convolution operation. The resulting edges are significantly cleaner with reduced noise compared to raw finite differences, using threshold τ=0.05.

Part 2: Fun with Frequencies

Sharpening by boosting high frequencies, hybrid images, and multi-resolution blending using Gaussian/Laplacian stacks.

2.1 Image "Sharpening"

Implemented unsharp masking to enhance image details by amplifying high-frequency components. The technique works by: (1) Creating a blurred version using an 11x11 Gaussian kernel with σ=2.0, (2) Subtracting the blur to isolate high frequencies: high_freq = img - blur, (3) Adding scaled high frequencies back: sharp = img + α * high_freq. I used α=1.5 to control sharpening strength. This is mathematically equivalent to sharp = (1+α)*img - α*blur, effectively boosting edges and fine details. Results are clipped to [0,1] to prevent overflow. The method successfully enhances architectural details in the Taj Mahal and recovers sharpness in naturally blurry images.

2.2 Hybrid Images

Created hybrid images that change appearance with viewing distance by combining different frequency bands from two images. The technique: (1) Extract low frequencies from image A using Gaussian filter (σ_low controls cutoff), (2) Extract high frequencies from image B by subtracting its Gaussian-blurred version (σ_high controls cutoff), (3) Sum the components: hybrid = A_low + B_high. Key to success is proper alignment - I implemented stretching (sx, sy) and translation (dx, dy) to match facial features. For face hybrids, I used σ_low=1.0 and σ_high=8.5 with weights wA=1.0, wB=1.0. The result appears as image B up close (high frequencies dominate) but transforms to image A from distance (only low frequencies visible). FFT analysis confirms the frequency separation.

2.3 Gaussian and Laplacian Stacks

Built Gaussian and Laplacian stacks to decompose images into frequency bands for multi-resolution analysis. Unlike pyramids, stacks maintain full resolution at each level. The Gaussian stack is created by repeatedly applying Gaussian blur (σ=2.0 per level): G[i+1] = gaussian_blur(G[i]). The Laplacian stack captures band-pass frequencies by differencing adjacent Gaussian levels: L[i] = G[i] - G[i+1]. With 6 levels, each Laplacian layer isolates progressively lower frequency bands, from fine details (L[0]) to broader features (L[4]), with G[5] containing only the lowest frequencies. This decomposition enables frequency-based image manipulation and seamless blending by operating on individual frequency bands.

2.4 Multiresolution Blending (Oraple)

Implemented Burt & Adelson's multi-resolution blending algorithm to seamlessly combine images using frequency-domain techniques. The algorithm: (1) Decompose both images into Laplacian stacks (6 levels, σ=2.0), (2) Create a Gaussian stack of the blend mask (smoothed with σ=13.0 for oraple, varying for others), (3) Blend each Laplacian level using the corresponding Gaussian mask level: L_blend[i] = mask[i]*L_A[i] + (1-mask[i])*L_B[i], (4) Reconstruct from blended Laplacian stack. The key insight: blending different frequencies with appropriately smoothed masks eliminates visible seams. Coarse features blend with heavily smoothed masks while fine details use sharper transitions. This creates natural-looking composites impossible with simple alpha blending.

Challenges & Reflections

Parameter Tuning: The most challenging aspect was finding optimal parameters for each technique. For edge detection, threshold τ required balancing sensitivity vs noise - too low captured noise, too high missed important edges. The DoG improvement came from understanding that Gaussian smoothing before differentiation is mathematically equivalent to convolving with DoG kernels, enabling single-pass edge detection.

Frequency Domain Insights: Hybrid images taught me how human perception processes different frequencies at varying distances. Critical parameters were σ_low (controls which face dominates at distance) and σ_high (controls near-view clarity). Failed attempts with σ_low > σ_high showed that proper frequency separation is essential - overlapping bands create muddy double-exposures rather than perceptual transitions.

Multi-resolution Blending: The key insight was that different frequency bands require different mask smoothing. Fine details need sharp transitions while coarse features need smooth ones. The Laplacian stack decomposition elegantly solves this by applying progressively smoother masks to lower frequencies. Reconstruction is surprisingly robust - the mathematics guarantee perfect image recovery from the stack.

Technical Learnings: Implementing convolution from scratch revealed the importance of kernel flipping and boundary handling. The progression from 4-loop to 2-loop to FFT-based convolution showed the computational benefits of algorithmic optimization. Working with both spatial and frequency domains reinforced their duality - some operations are natural in one domain but complex in the other.
